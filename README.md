# Himendra Gusain — Personal Website

Static personal developer website built with:
- HTML
- CSS
- Vanilla JavaScript

No React, Node, npm, database, backend, or build step required.

## Deploy from iPhone

Upload the contents of this folder to any static hosting service that accepts a ZIP/repository.

Before publishing, replace:
- `YOUR-LINKEDIN-USERNAME` in `index.html`
- `YOUR-EMAIL@example.com` in `index.html`
